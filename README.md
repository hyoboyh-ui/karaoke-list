# カラオケリスト

カラオケの持ち歌リスト。店内でスマホから「探す・歌った・その場で追加」が片手でできる1画面アプリ。

- 画面：静的ファイル（`index.html` / `app.js` / `style.css`）を GitHub Pages で配信。画面はスマホに保存され、電波が弱くてもすぐ開く
- 保存：Google スプレッドシート「カラオケリスト」。Apps Script（`gas/Code.gs`）が読み書きし、パスワードでログインした端末だけが使える
- 変更はまず端末に保存し、つながったときにまとめて送る（後から書いた方が勝つ）

準備と運用の手順は [SETUP.md](SETUP.md)。
